## Proyectos destacados

### [JuanDev](https://github.com/SoliDeoGloria123/JuanDev) — portafolio estilo Windows XP
Portafolio frontend con una interfaz inspirada en Windows XP: responsivo, con juegos en el navegador (Snake, Tetris, Memory y Pong), reproductor de música, formulario de contacto con EmailJS y un fondo espacial con Three.js. Hecho con HTML5, CSS3 y JavaScript.

### [SiSENA](https://github.com/SoliDeoGloria123/SiSENA) — alquiler de bicicletas del SENA
Sistema web para que aprendices y funcionarios registren, alquilen y devuelvan bicicletas, consulten su historial e inscriban ciclopaseos. El administrador gestiona bicicletas y usuarios, ve estadísticas y ubica las bicicletas en un mapa (Leaflet). Backend en Python y Flask, API REST documentada con Swagger, SQLite con SQLAlchemy, y frontend en HTML, CSS y Bootstrap.

### [Lara](https://github.com/SoliDeoGloria123/Lara) — generador CLI de proyectos FastAPI
Herramienta de línea de comandos (también en [PyPI como `lara-cli`](https://pypi.org/project/lara-cli/)) que crea APIs REST con FastAPI, autenticación JWT y modelos a partir de una base de datos existente. Pensada para competencias y prototipos rápidos.

### [Luckas](https://github.com/SoliDeoGloria123/Luckas) — sistema de gestión full stack
Aplicación con interfaz pública y panel administrativo (roles de administrador, tesorero y seminarista). Backend en JavaScript/Node, frontend en React y apoyo en Python.

### [Moe](https://github.com/SoliDeoGloria123/Moe) — inventario móvil
Sistema de inventario con React Native y TypeScript, backend en Express y SQLite, autenticación JWT y control de acceso por roles (administrador y coordinador), con CRUD de usuarios, categorías y productos.

### [LuckasEnt](https://github.com/SoliDeoGloria123/LuckasEnt) — comparación de precios
Proyecto web para comparar precios de la canasta familiar en supermercados de Colombia, con HTML, CSS, Python y Docker.
